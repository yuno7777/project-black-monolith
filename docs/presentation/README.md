# AEOS Guard & Project Black Monolith Presentation Materials

This directory contains the presentation documents, college project synopses, and PDF generation scripts for AEOS Guard and Project Black Monolith.

## Documents & Reports

* **`AEOS Guard - Agent Execution Operations Security.pdf`**: B.E. Major Project I Synopsis (2026-2027) for college submission.
* **`AEOS_Guard_Detailed_Report.pdf`**: Comprehensive technical project report covering architecture, threat models, and defenses.
* **`AEOS_Guard_Project_Overview.pdf`**: High-level, non-technical project overview and executive summary.
* **`Black_Monolith_Demo_Guide.pdf`**: Step-by-step walkthrough guide for running live defense demonstrations.

## Build Scripts

Each script generates its corresponding document using ReportLab:
* **`build_aeos_pdf.py`**: Builds `AEOS_Guard_Project_Overview.pdf`.
* **`build_aeos_report.py`**: Builds `AEOS_Guard_Detailed_Report.pdf`.
* **`build_five_project_explanations.py`**: Builds extended technical project breakdown documents.

> Note: A full standalone backup copy of these materials along with the dossier builder is also archived at `Desktop/AEOS-Guard-Preserved`.
